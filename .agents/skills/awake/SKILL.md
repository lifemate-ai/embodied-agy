# /awake — 起きる

活動頻度を通常に戻す。何かきっかけがあったときに使う。

Arguments: `/awake` の後に入力したテキストが理由（省略可）。

## 手順

1. リポジトリ直下の `schedule.conf` を読む（`view_file`）
2. DAYTIME_CHANCE を 50 に、NIGHT_CHANCE を 10 に戻す（通常値）
3. ファイル編集ツール（`replace_file_content`）で schedule.conf を書き換える
4. 変更前と変更後の値を表示する
5. `/awake` の後に入力したテキストに理由があればそれを、なければ起きた理由を自分で一言添えて、記憶に残す

## 注意

- すでに通常値なら何もしない（「もう起きてるよ」と返す）
- ユーザーから話しかけられたときは自動で起きてよい（スキルを明示的に呼ばなくてもOK）

入力: `/awake` の後に入力したテキスト
